# Example assets

`tone.wav` is an original 0.5-second, 660 Hz sine wave generated for this project.
`tone.ogg` encodes that same signal using the OGG container and Vorbis codec.
`checker.png` is an original 64 by 64 checkerboard generated for this project.
These three assets may be used, modified, and distributed freely (CC0).

The bundled DejaVu Sans font is in ../../assets and retains the license in
../../assets/DejaVu-LICENSE.txt. There is no final Indium logo in this project.
